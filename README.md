# Vocalinkfind

スマートフォン・タブレット・PCに対応した位置情報共有Webアプリ。

## 現在のバージョン

v1.0.0

## 現在実装済み

- レスポンシブな初期画面
- Leafletによる地図表示
- ブラウザのGeolocation APIによる現在地取得
- 現在地のマーカー・精度円表示
- スマートフォン / タブレット / PC向けレイアウト

## 今後の開発

1. アカウント登録・ログイン
2. 自分のプロフィール
3. 友達・共有相手の追加
4. 位置情報共有
5. グループ機能
6. Supabase Realtimeによるリアルタイム同期
7. 共有期限・共有停止
8. 位置情報のプライバシー設定

## 開発方針

位置情報を扱うため、共有相手・共有期限・位置情報の保存範囲を明確にした上で機能を追加する。
