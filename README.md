# VocalinkFind

スマートフォン・タブレット・PCに対応した位置情報共有Webアプリ。

## 現在のバージョン

v1.1.0

## 実装済み

- レスポンシブな位置情報共有UI
- Leafletによる地図表示
- Supabase Authによるログイン・アカウント作成
- ブラウザGeolocation APIによる現在地の継続取得
- 自分の位置情報をSupabaseへ保存
- 共有コードの発行
- 共有コードによる共有への参加
- 共有相手の位置情報表示
- Supabase Realtimeによる位置更新
- 共有期限の設定
- RLSによる位置情報アクセス制御

## 開発方針

位置情報はセンシティブな情報として扱い、共有相手・共有期限・位置情報の保存範囲を明確にした上で機能を追加する。
